Conectar con GitHub

Los registros se guardan como un archivo JSON dentro de un repositorio tuyo, usando la API de GitHub. Crea un token de acceso personal (fine-grained) limitado solo a ese repositorio, con permiso Contents: Read and write. El token se guarda únicamente en este navegador (localStorage), nunca se envía a ningún otro sitio. Si usas una PC compartida, ciérralo con "Borrar token" al terminar.
